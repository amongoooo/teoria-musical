# Teoría Musical 🎹

App web gratuita para aprender **teoría musical** y **producción en FL Studio** con lecciones cortas e interactivas (con audio) y retos prácticos.

👉 **Pruébala:** https://amongoooo.github.io/teoria-musical/

Hecha con Vite + React, Tailwind CSS y Tone.js. Se publica sola en GitHub Pages con cada cambio en `main`.
